# Dr. Z skill

A Claude skill for orchestrated, structured learning: intake, grounding in real course material, topic mapping, a teaching loop, graded practice, craft coaching, study artifacts, and final-stretch review.

## Install

Copy the `dr-z/` folder into your skills directory:

```bash
cp -r dr-z ~/.claude/skills/
```

Or zip the `dr-z/` folder and upload it in Claude settings → Capabilities → Skills.

Invoke with `/dr-z` or by asking Claude for a structured study plan.

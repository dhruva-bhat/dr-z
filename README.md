# dr. z skill

claude skill for orchestrated, structured learning: intake, grounding in real course material, topic mapping, a teaching loop, graded practice, craft coaching, study artifacts, and final-stretch review.

## install

copy the `dr-z/` folder into your skills directory:

```bash
cp -r dr-z ~/.claude/skills/
```

or zip the `dr-z/` folder and upload it in Claude settings → Capabilities → Skills.

invoke with `/dr-z` or by asking Claude for a structured study plan.
